# Audio Words - recordings for "Tap to hear"

Purpose: the recordings played by the Tap to hear buttons (code: Assets/Main/Scripts/Audio/WordAudio.cs).

Put one audio file per word or phrase in the folder of its language (Cebuano, Ilonggo, Tagalog). The file name is the text in lower case, letters and digits only, spaces as underscores: BAKI -> baki, "Maayong buntag" -> maayong_buntag. wav, mp3 and ogg all work. Do not rename this folder or the language folders: the game loads the files from Resources by name.

The full list of files to record, with the exact names, is in Mockups/audio_recording_list.md. A word without a file shows "No recording for this word yet" when tapped.
