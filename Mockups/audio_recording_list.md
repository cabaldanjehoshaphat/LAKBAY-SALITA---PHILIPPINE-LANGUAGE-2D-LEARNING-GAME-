# Tap to hear - recording list

Purpose: every word and phrase that needs a recording for the 'Tap to hear' buttons, per language, with the exact file name the game looks for. Put each recording in `Assets/Main/Resources/Audio Words/<Language>/` (Cebuano, Ilonggo or Tagalog) with that file name (wav, mp3 or ogg). Words without a file show 'No recording for this word yet' when tapped, so the recordings can be added a few at a time.

Tips: record one word or phrase per file, in a quiet room, say it once at a natural speed, leave about half a second of silence before and after, and keep the same volume for every file. The file name is the text in lower case, letters and digits only, spaces as underscores (for example `maayong_buntag.wav`).
